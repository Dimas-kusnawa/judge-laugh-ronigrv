A program that writes one funny line to `/output/entry.txt` (112 characters, inside the 200-character cap). The agent asks its human for clearer instructions, and the human answers with a 14-minute voice note that just says "you know what I mean" — the least clear format possible, delivered as if the vagueness itself were the instruction.

## Run it

```sh
python3 main.py
```
